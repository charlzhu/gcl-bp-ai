# Project Context

## 项目名称
经营计划智能助手，仓库名 `gcl-bp-ai`。

## 项目定位
面向经营计划部门和业务同事的业务智能助手。当前优先服务物流一期、试运行演示和真实业务反馈闭环。

## 当前优先范围
- 物流一期：自然语言查询、结构化查询、明细查询、跨来源对比查询、结果解释与日志追踪。
- 计划 BOM：上传、查询、问答和材料明细能力已具备基础验收能力。
- 当前不是纯文档 RAG 优先，而是结构化查询、业务规则、NLU、前后端可用性优先。

## 当前核心入口
- 前端真实入口：`/smart-chat`。
- 物流 data-qa 旧入口：`/logistics/data-qa`，当前重定向到 `/smart-chat`。
- BOM 数据管理入口：`/bom-data`。
- 试运行说明入口：`/trial-guide`。

## AI 协作方式
- Hermes Agent 负责总控、任务拆解、调用 Codex CLI、生成报告。
- Codex CLI 负责读取本地仓库、修改代码、运行命令和输出结果。
- Git 负责记录改动和回滚。
- `ai/` 目录负责保存任务、规则、上下文、角色和报告。

## 重要原则
1. 优先保证项目稳定。
2. 不追求一次性大而全。
3. 每次任务必须可验证。
4. 不允许为了通过测试而破坏业务逻辑。
5. 修改后必须生成报告。
