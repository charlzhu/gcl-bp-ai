## 1. 附件一：GCL功率测试基准（V2.1）TOPCon 26.04.13.xlsm

### 1.1 文件位置

```text
ai/inbox/attachments/GCL功率测试基准（V2.1）TOPCon 26.04.13.xlsm
```

### 1.2 文件用途

这是业务最新版功率预测模型文件，不是普通业务明细表。

该文件包含多个版型 Sheet，每个 Sheet 内部通过配置项、供应商效率分布、Excel 公式和 VBA 写值逻辑计算组件功率档位分布。

后续默认用途：

1. M1.5 补充审计的主分析文件。
2. M2 功率模型版本化入库的首个目标文件。
3. M3 确定性计算引擎 parity 的主要基准文件。
4. M4/M5 的 active 模型版本来源。

### 1.3 M1.5 补充审计摘要

新版补充审计结论：

1. Sheet 数量仍为 12：10 个版型模型页 + `标板基准` + `更改履历`。
2. 版型模型页未变：
   - `NT10-72GDF`
   - `NT10-78GDF`
   - `NT12R-66GDF`
   - `NT12R-66GDF (2.0)`
   - `NT12-66GDF`
   - `NT12R-78GDF `（Sheet 名末尾仍有空格）
   - `NT12R-48GDF`
   - `NT12R-48BGDF`
   - `NT12R-54GDF`
   - `NT12R-54BGDF`
3. 配置区仍为 `A1:Y27`。
4. 电池效率区仍为 `C29:C48`。
5. 当前供应商投产比例仍为 `D29:D48`。
6. 供应商效率分布区仍为 `C77:Y96`。
7. 功率档位区仍为 `K28:T28` 或 48/54 系列有效 8 档。
8. `标板基准` 页变为 `A1:E10`，新增 `功率最优` 列。
9. `更改履历` 更新到 2026.04.13。
10. 新版仍有 `NT12R-66GDF!R30/R32` 需要 `semantic_fixed_mode`。

### 1.4 对开发的要求

必须注意：

1. 不能把该 Excel 简单当成静态数据表导入。
2. 不能只读取现有公式结果就认为完成。
3. openpyxl 不执行 VBA，也不能可靠重算 Excel 公式。
4. 必须审计 Excel 结构、公式、宏依赖和核心计算逻辑。
5. 必须明确哪些数据入库，哪些逻辑由后端计算引擎复现。
6. 后续需要支持周期性导入新版本 Excel。
7. 每次导入都必须生成新的模型版本。
8. 智能问答默认使用当前 active 功率模型版本。
9. 不能将当前 Excel 的某一组结果 hardcode 到代码中。
10. 不允许让 LLM 直接读 Excel 后自由回答功率预测结果。
11. M2 必须保存 `formula_policy = semantic_fixed_mode`。
12. M2 必须记录 parse issues，尤其是 `R30/R32` 语义修正、异常供应商标题、`#REF!`、占位供应商。

### 1.5 需要重点分析 / 入库的内容

1. 所有 Sheet 名称。
2. 每个 Sheet 对应的组件版型。
3. 上方配置选择区。
4. 配置项和配置选项。
5. 配置选项对应的功率影响值。
6. 电池效率区。
7. 供应商效率分布区。
8. 功率档位范围。
9. 组件预测模型档位分布。
10. 标板基准数据和 `功率最优` 列。
11. 核心计算公式。
12. VBA / 宏是否参与核心计算。
13. `formula_policy`。
14. parse issues / warnings。
15. 后端复现计算逻辑的方案。
16. 抽样校验方案。

## 2. 附件二：BOM配置搭配问询：.docx

### 2.1 文件用途

这是业务问题样例文件，用于理解业务员希望怎么提问，以及系统应该支持哪些问答类型。

该文件只作为：

1. 问题类型参考。
2. 自然语言问法参考。
3. 槽位结构参考。
4. 答案展示格式参考。

### 2.2 重要说明

非常重要：

1. 文档中的版型号是假的。
2. 文档中的订单号是假的。
3. 文档中的评审号是假的。
4. 文档中的项目名是假的。
5. 文档中的问题不能直接作为真实验收问题。
6. 文档中的问题不能 hardcode。
7. 不能为了让文档里的问题通过而伪造数据。
8. 不能将文档中的假问题写成固定测试基线。

正式测试必须：

1. 基于当前项目中真实存在的 BOM 数据。
2. 基于实际导入的功率预测模型。
3. 自行生成真实可执行测试题。
4. 使用后端确定性计算结果作为答案来源。
5. 测试题和预期结果必须可追溯。

### 2.3 该文档体现的问题类型

1. BOM 配置查询类：查订单玻璃、间隙贴膜、焊带、汇流条、接线盒规格等。
2. 功率预测类：指定版型 / 配置 / 标板 / 供应商，查询效率段和功率档位分布。
3. BOM + 功率预测混合类：订单 + 目标功率档 + 目标比例 → 推荐供应商和效率段。
