# PLAN_BOM_LEADER_BRIEFING

## 一句话结论

计划 BOM 问答 Wave2 已具备小范围业务试运行条件：系统能基于真实 BOM Excel 数据回答一批高频材料规格类问题，对条件不足的问题会追问，对当前数据不支持的问题会解释原因。

## 解决的问题

- 业务人员不需要逐个打开 BOM Excel 查五类关键材料。
- 系统可以按订单、型号、国家、年份、材料类别等条件组织查询。
- 对同类订单、多个订单或版本类问题，系统能给出表格、对比或追问。

## 当前能力程度

- A=86：当前真实数据和能力可以直接回答。
- B=40：需要补充订单范围、版本、材料范围、对比对象或业务口径后再回答。
- C=3：当前 BOM 数据或业务规则不支持，系统会拒答解释。
- D=0：没有解析失败或待确认台账项。

## 为什么不是所有问题都直接回答

BOM 问题经常包含“这批订单”“核心方案是否一致”“能不能复用”“功率倒推”等业务口径。若缺少订单范围、版本、材料范围或业务规则，直接回答会产生误导，因此系统保留 B 类追问和 C 类拒答。

## 如何避免乱答

- 查询事实只来自标准化 BOM 数据。
- qwen-plus 只做意图/槽位候选和表达优化。
- 订单、材料、版本必须经过索引校验。
- 非核心材料不进入核心五类 schema。
- B/C 不能被 LLM 改写成 A。

## 试运行方式

- 选择少量计划、采购、产品、经营人员使用。
- 先上传或使用已导入 BOM 数据。
- 用真实问题提问，按 A/B/C/Bug/Data/Biz 分类反馈。
- 每周复盘高频 B 类和 C 类，确认业务口径后再决定是否工程化收口。
