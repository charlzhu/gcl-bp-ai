### 4.2 电池效率区

- 位置：`C29:C48`
- 结构：从起始效率递增，每行 `+0.1%`，如 `C30 = C29 + 0.1%`。
- 对应投产比例：`D29:D48`，供应商选择时由 VBA 从 `C77:Y96` 中按列复制到 `D29:D48`。
- 面积：`E29:E48`，由 `B14` 复制。
- 单片功率：`F29:F48 = C行 * E行 / 1000`
- 理论功率：`G29:G48 = F行 * cell_count`，其中 cell_count 随版型为 48、54、66、72、78。
- CTM 值：`H29:H48 = I行 / G行`
- 实际功率：`I29:I48`，以 `I36` 为基准中心，向上 / 向下按相邻 CTM 做 `±0.15%` 推导。

### 4.3 功率档位区与组件预测模型档位分布

- 功率档标题：`K28:T28`（大多数 10 档）；48/54 版型有效档位为 `K28:R28`，后面的 `核验` 不应当作为功率档。
- 档位间隔：5W。
- 组件预测模型档位分布：`K29:T48` 或 `K29:R48`。
- 核验列：`U29:U48` 或对应有效档后一列，通常 `SUM(档位分布)`。

核心公式样例（以 `NT12R-66GDF` 为例）：

```excel
F36 = C36 * E36 / 1000
G36 = F36 * 66
H36 = I36 / G36
K36 = NORMSDIST((I36-$K$28)/B15) - NORMSDIST((I36-$L$28)/B15)
L36 = NORMSDIST((I36-$L$28)/B15) - NORMSDIST((I36-$M$28)/B15)
U36 = SUM(K36:T36)
```

解释：对每个效率段，根据该效率段对应的实际功率 `I行`、标准差 `B15`、相邻功率档边界，计算落入每个 5W 档位的概率。

### 4.4 供应商效率分布 / 电池产出分布区

- 标题行：`A76` = 电池产出分布，`B76` = 电池效率，`C76:Y76` 引用供应商名称。
- 效率段：`B77:B96` 引用 `C29:C48`。
- 供应商效率分布：`C77:Y96`，稀疏矩阵；只有有数据的供应商可参与推荐。
- 选择供应商时，VBA 把对应列的 `C77:C96` / `D77:D96` 等复制到 `D29:D48`。
- 加权功率分布：`K51:T70 = D29:D48 * K29:T48`。
- 累计产出：`K71:T71 = SUM(K51:K70)`，对应最终该供应商下各功率档占比。

后端必须复现：供应商效率分布 × 每效率段功率档概率 的加权求和。

## 8. VBA / 宏审计

`olevba` 解析到 `ThisWorkbook.cls`、多个 `SheetXX.cls`。`ThisWorkbook` 为空；多个模型 Sheet 上存在相同的 `Worksheet_SelectionChange(ByVal Target As Range)` 事件。

宏的核心逻辑：

```vb
hang = (r = 3) Or (r = 6) Or (r = 9) Or (r = 12) Or (r = 17) Or (r = 20) Or (r = 23) Or (r = 26)
If Cells(r, c) <> "" And Target.Column >= 3 And Target.Column <= 25 And Target.Row <= 200 And hang Then
    If (r <> 12) Then
        Cells(r, 2) = Cells(r + 1, c)
    Else
        Cells(r, 2) = Cells(r + 1, c)
        Cells(r + 2, 2) = Cells(r + 2, c)
        Cells(r + 3, 2) = Cells(r + 3, c)
    End If

    If r = 9 Then
        Range("d29:d48") = Range(Cells(77, c), Cells(96, c)).Value
    End If

    Cells(36, 9) = Cells(1, 10) + Cells(3, 2) + Cells(6, 2) + Cells(12, 2) + Cells(17, 2) + Cells(20, 2) + Cells(23, 2) + Cells(26, 2) + Cells(9, 2)
    Range("e29:e48") = Cells(14, 2).Value
End If
```

结论：**VBA 参与核心计算**，至少参与三件事：

1. 把用户选择的配置影响值写入 `B3/B6/B9/B12/B17/B20/B23/B26`。
2. 电池尺寸选择时同步写入 `B14` 面积、`B15` 标准差。
3. 供应商选择时把 `C77:Y96` 供应商效率分布写到 `D29:D48`。
4. 每次选择后重新计算 `I36 = J1 + B3 + B6 + B9 + B12 + B17 + B20 + B23 + B26`。
5. 把 `B14` 面积写入 `E29:E48`。

后端不能依赖 Excel 宏运行；后端必须把上述宏逻辑翻译成确定性 Python 计算。

## 9. 公式依赖链

后端需要复现的依赖链：

```text
版型 + 配置 + 标板 + 供应商
↓
读取模型版本、版型基础参数、配置项影响值、供应商效率分布
↓
center_power = J1 + ribbon_delta + glass_delta + supplier_delta + cell_size_delta + cable_delta + busbar_delta + process_delta + benchmark_delta
↓
面积 area = 选中电池尺寸的面积
标准差 std_dev = 选中电池尺寸的标准差
↓
效率段 efficiency_i = 起始效率 + 0.1% * i
↓
single_cell_power_i = efficiency_i * area / 1000
module_theoretical_power_i = single_cell_power_i * cell_count
↓
以 center_power / I36 为中心推导 I29:I48 实际功率
↓
probability_i,power_bin = CDF((actual_power_i - lower_bin)/std_dev) - CDF((actual_power_i - upper_bin)/std_dev)
↓
weighted_power_bin = Σ supplier_efficiency_ratio_i * probability_i,power_bin
↓
目标功率档 / 目标比例匹配度
```

其中 `NORMSDIST` 需要等价实现为标准正态分布 CDF。

## 11. 风险与已确认口径

### 11.1 固定行列依赖风险

该 Excel 强依赖固定行列：配置行固定为 3/6/9/12/17/20/23/26，模型区固定为 29:48、51:70、71、76:96。后续解析器必须校验锚点文本，例如 `A3=焊带选型`、`A6=玻璃选型`、`A76=电池产出分布`，否则应拒绝导入或标记错误。

### 11.2 隐藏行列风险

- 多数模型页隐藏 `23:24` 或 `23:25`，但这些行包含“电池工艺 / 影响因子2”，不能因隐藏而忽略。
- 48/54 系列隐藏 `62:63` 等行，仍可能影响加权分布范围判断。
- 部分页隐藏 `T` 或 `R` 列；导入器不能只读可见列，应按有效档位标题和核验列判断。

### 11.3 数据验证风险

openpyxl 未检测到数据验证下拉项（data validation count = 0）。当前“点击选项”主要依赖 VBA + 格式高亮，不是 Excel 数据验证下拉。后端导入器不能期待存在下拉列表定义。

### 11.4 疑似公式复制错误与已确认处理口径

M1 旧版曾在 6 个 10 档模型页发现 `R30:R34` 疑似公式复制错误。M1.5 新版复核后，问题已大幅减少，但 `NT12R-66GDF!R30/R32` 仍存在第二段引用 `L行-$S$28` 的形态。

业务已确认采用：

```text
formula_policy = semantic_fixed_mode
```

因此后端计算引擎应按公式语义修正为 `I行-$S$28`，并在 M2 解析 issue 中记录原始公式位置和修正策略；M3 抽样校验以 `semantic_fixed_mode` 为正式系统口径。

### 11.5 宏安全与执行风险

- 宏没有外部网络、文件删除、Shell 执行等高风险关键词；但 `olevba` 检测到 Hex Strings 提示，需保守记录为安全提示。
- 后端不应执行宏，只解析参数并重写计算。

### 11.6 业务确认项状态

M1.5 已固化关键业务口径，详见 `docs/PLAN_POWER_BUSINESS_CONFIRMATION.md`：

1. 公式策略：`formula_policy = semantic_fixed_mode`。
2. BOM 中“间隙贴膜”等同于功率模型中的“间隙铝膜”。
3. BOM 中“接线盒 300/200”映射到功率模型里的“线缆长度 +300/-200mm”。
4. “北德 / 新北德 / TÜV北德”统一映射为“新北德”。
5. “计量院”统一映射为“中国计量院”。
6. “莱茵”统一映射为“莱茵基准”。
7. “NT12/66GDF”统一映射为“NT12-66GDF”。
8. “NT12R/66GDF”统一映射为“NT12R-66GDF”。
9. `NT12R-66GDF (2.0)` 作为独立模型页，不应被普通 `NT12R-66GDF` 默认吞并。
