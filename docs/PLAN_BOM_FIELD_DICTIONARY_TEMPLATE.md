# 计划 BOM 字段字典正式版

## 一、文档用途

本文件用于固化 `计划 BOM` 一期字段口径、数据源结构、主键规则和常见业务口语映射。

| 字段名 | 中文名称 | 字段类型 | 业务含义 | 示例值 | 是否筛选 | 是否展示 | 备注 |

| 修订内容 | 修订内容 | 长文本 | 版本变更说明或特殊要求 | `新北德640W...` | 是 | 是 | 可能出现替代标识 |

当前版本判定：

1. 先按 `生效日期` 倒序。
2. 生效日期相同或缺失时，按 `版本号` 自然序倒序。
3. 完全冲突时返回“版本待人工确认”。

## 九、替代料字段边界

当前不新增独立替代料结构化字段。

一期处理规则：

- `备注 / 修订内容 / 物料名称` 中出现明确替代标识时，原样展示。
- 不拆解主替代 / 次替代。
- 不推断生效条件。
- 不输出结构化替代关系。

---

## 十、SAP 与 Excel 字段兼容原则

- Excel 导入和 SAP 导入共用同一套唯一键。
- SAP 字段下发后，必须映射到本文件定义的逻辑字段。
- 同一 `订单号 + 版本号` 同时存在 SAP 与 Excel 时，以 SAP 为准。
- Excel 导入数据保留 `manual_import_source` 标记。
- SAP 切换细则见 `PLAN_BOM_SOURCE_SWITCH_RULE.md`。
