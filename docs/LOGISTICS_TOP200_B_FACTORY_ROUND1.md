# 物流域 Top200 高价值 B 题工厂化收口 Round1

## 1. 本轮目标

本轮不是继续按单题逐条挤牙膏，而是按“题族 + 能力点 + 批量回归”的方式，先吃掉 Top200 中最值得优先收口的一批高价值 B 题。

当前 round1 只处理第一批 `5` 个题族。

---

## 2. 本轮选择的 5 个题族

| 题族 | 题数 | 选择原因 |
| --- | ---: | --- |
| 历史省份累计总费用类 | 8 | 高频、管理价值高，只差“历史累计”正式口径放行 |
| 历史承运商年度经营KPI类 | 8 | 只差术语归一，补完即可复用现有年度 KPI query_key |
| 2026月度承运商总运费类 | 8 | 2026 经营看数高频，主体是参数抽取和系统费用复用 |
| 历史车型总车次类 | 3 | 只差车型别名和车次问法识别，收口成本低 |
| 2026月度单瓦成本类 | 3 | 只差系统单瓦成本正式 query_key，收益明确 |

本轮总共处理题数：`30`

---

## 3. 批量收口策略

本轮不是逐题 hardcode，而是统一走 5 类能力增强：

1. **术语归一增强**
   - 承运量 / 运输量 / 发货量 统一归到历史承运商 KPI

2. **时间表达归一**
   - 历史累计口径正式支持
   - 零前缀年份如 `025年` 归一成 `2025年`

3. **槽位提取增强**
   - 承运商名称抽取
   - 车型抽取

4. **query_key 参数化 / 复用**
   - 历史省份总费用
   - 历史车型总车次
   - 2026 月度承运商总运费
   - 2026 月度单瓦成本

5. **规则层条件补齐**
   - 只在安全边界内直接放行
   - 对仍缺稳定字段或口径的题，继续保留 B 类澄清

## 7. 本轮继续保留在 B 的题

### `RAW052`
问题：
- 从合肥基地始发，26年1-2月客户海南创维新能源投资有限公司总运费多少

继续保留 B 的原因：
- 当前仍缺“基地”稳定映射字段
- 不能把基地口径硬猜进正式系统过滤条件

### `RAW056`
问题：
- 2026年阜宁基地1月份晶茂物流总计运费是多少钱

继续保留 B 的原因：
- 同样依赖“基地”稳定映射字段
- 现阶段不适合假装已经有可靠字段

### `RAW057`
问题：
- 2月份单W运输成本是多少（（2月运费总价格+额外费用）/运输组件总W数）

继续保留 B 的原因：
- 只有月份，没有年份
- 同时混入“额外费用”口径，当前年份与费用组成仍需先澄清

本轮已经形成正式自动回归集，不再是人工逐题复核：

- 脚本：
  - `scripts/logistics_top200_b_factory_round1.py`
- 报告：
  - `tmp/logistics_question_bank/logistics_top200_b_factory_round1_report.json`

1. 读取 Top200 配置和现有 P1/P2 基线
2. 识别当前有效高价值 B 题
3. 按题族组织 round1 处理对象
4. 真实调用当前 `data-qa` 主链路
5. 输出每题结果、题族汇总、A/B/C 变化
