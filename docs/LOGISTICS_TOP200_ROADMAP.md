# 物流域高频 Top200 收口路线图

## 1. 为什么现在先做 Top200，而不是继续平均推进 903 条

当前物流域题库总量为 `903` 条，虽然已经完成：

- 物流数据问答 MVP 收口
- A 类 `75` 条行为级自动回归
- A 类关键题 `20` 条精确答案断言回归
- B/C 类响应策略初步固化

但这不等于物流域题库已经整体收口。继续平均推进 `903` 条会带来三个问题：

1. 高频高价值问题与长尾问题混在一起，研发优先级会失焦。
2. 资源容易消耗在预测、开放讨论、额外费用明细等当前不该优先投入的题上。
3. 看起来“持续推进”，但真正对业务和领导有价值的题覆盖仍然不够集中。

因此本轮先把最值得收口的一批题显式筛出来，形成正式的 Top200 路线图。

## 2. Top200 的筛选原则

Top200 不是主观拍脑袋挑题，而是基于当前分类产物，按以下四个维度做可解释筛选：

### 2.1 业务真实频率

- `73` 题原始业务补充问法权重最高
- `230` 题物流主体题权重居中
- `600` 题新增结构化题权重居后

原因是：当前阶段更优先贴近业务真实会问的问题，而不是只追求结构题数量。

### 2.2 管理价值

优先看以下方向：

- 发运量 / 运量 / MW
- 运费 / 总费用 / 单瓦成本
- 车次 / 总车数
- 承运商经营 / 签收率
- 区域 / 省份 / 城市 / 基地
- 客户 / 项目 / 项目地
- 排名 / 对比 / 月度趋势
- 2026 正式系统经营数据

### 2.3 数据可算性

- A 类优先级最高
- B 类次之
- C 类最低
- 已有正式 `query_key` 的题额外加分

### 2.4 收口成本

- A 类直接纳入持续回归
- B 类优先选择最容易通过澄清模板或小幅扩展进入 A 类的题
- C 类只保留高频高价值的一小批，用于明确“当前不支持边界”

### 2.5 分类配额

为了避免 Top200 被单一分类吞没，当前采用固定配额：

- A 类：全量纳入 `75`
- B 类：取前 `100`
- C 类：取前 `25`

这样得到的 Top200 既能指导“下一步先收什么进 A”，也能保留一批高频但当前必须停在 B/C 的题。

## 4. Top200 中最值得优先推进进 A 类的题

当前最值得优先推进进 A 类的，不是所有 B 类题，而是 **P1/P2 中那 42 条高价值 B 类题**。它们的共同特点是：

1. 业务真实频率高；
2. 指标方向明确，主要卡在时间范围、拆分维度或展示口径；
3. 大多不需要新域、新系统或复杂算法；
4. 很适合通过“澄清模板细化 + 小幅 query_key 扩展”逐步收进 A 类。

代表题包括：

- `RAW052` 帮我看一下从合肥基地始发，26年1-2月客户：海南创维新能源投资有限公司 总运费多少
- `RAW066` 2026年1月份总发运量是多少MW？总共发了多少车次？
- `RAW056` 帮我查一下2026年阜宁基地1月份晶茂物流总计运费是多少钱
- `RAW013` 请告诉我25年各家物流承运商分别承运量是多少，占比多少，运费总额多少，表格告诉我
- `RAW038` 统计一下24年创维客户发货的项目地运费金额超过20万的收货地址，并分别列出询比价和招标的发运量
- `RAW031` 2023年各物流承运商年度运输费用各是多少？
- `RAW022` 2025年各物流承运商年度运输费用各是多少？
- `RAW057` 2月份单W运输成本是多少（（2月运费总价格+额外费用）/运输组件总W数）
- `RAW028` 帮我做一个23年每个月的运费对比
- `RAW019` 25年物流公司承运量

这些题不适合继续停留在“通用澄清”，而应作为下一阶段最优先收口对象。

## 5. 哪些题即使高频，当前也应继续停在 B/C

高频不等于当前就应该拉进 A 类。当前 Top200 里仍有一批题，即使业务高频，也应继续保留在 B/C：

### 5.1 继续停在 B 类的典型情况

- 统计对象明确，但缺时间范围
- 缺拆分维度或结果指标
- 口径存在多种合理解释，不能直接给结果

例如：

- `RAW041` 2024年1月份客户华阳的总发运量是多少MW？
- `RAW048` 问题2：24年 1-12月 目的地是江苏省的单瓦价是多少
- `RAW051` 帮我看一下26年2月客户：广东粤电阳西新能源有限公司总运费多少

### 5.2 继续停在 C 类的典型情况

- 额外费用原因/项目/明细
- 预测、趋势、波动区间
- ETA/时效推理
- 开放设计/模型类

代表题包括：

- `RAW065` 2026年1月份额外费用产生多少金额，分别是什么项目？什么原因产生的？
- `RAW002` 2026年1月额外费用总额及项目、金额、原因明细
- `Q325` 若 extra_cost_audited 任务持续增加，未来一个月额外费用审核压力会集中在哪些承运商和省份？
- `Q313` 结合历史元/瓦、距离与2026目的地结构，预测未来3个月成本压力最大的前五个送达省份。

这些题即使高频，当前也不应为了提高覆盖率硬拉进 A 类。

## 8. 当前是否已经形成可执行的 Top200 收口路线图

结论：**已经形成。**

原因是当前已经明确了：

1. 哪 `200` 条题最值得优先投入；
2. 这 `200` 条题里 A/B/C 各自有多少；
3. 哪些题应优先继续收进 A 类；
4. 哪些题即使高频也必须继续停在 B/C；
5. 第一优先批次和第二优先批次分别是什么。

这意味着下一步开发不需要再从 `903` 条里重新找方向，而可以直接围绕 Top200 继续推进。

## 9. 下一阶段建议

最合理的下一步不是继续平均推进 `903` 条，而是：

1. 先吃掉 P1 的 `16` 条高价值 B 类题，优先细化澄清模板或扩最小 query_key；
2. 再推进 P2 的 `26` 条高价值 B 类题；
3. 同时把 P1/P2 里的 A 类题继续纳入更严格的精确断言回归；
4. P3 中的 `25` 条 C 类题继续维持不支持边界，不建议当前投入。

做到这一步后，物流域才真正从“MVP 收口”走向“高频问题逐批收口”。
