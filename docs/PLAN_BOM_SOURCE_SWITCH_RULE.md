# 计划 BOM 数据源优先级与切换规则

## 一、文档用途

本文件用于固化 `计划 BOM` 一期开发阶段和后续 SAP 正式接入阶段的数据源优先级、冲突处理、切换动作和兼容边界。

本文件只定义规则，不代表已经进入 SAP 接入代码开发。

---

## 二、适用范围

适用于：

- BOM 一期 Excel 开发期入库。
- 后续 SAP 业务视图正式接入。
- Excel 与 SAP 同时存在同一 BOM 时的优先级处理。
- SAP 切换时的数据重建、索引重建和去重。

不适用于：

- 功率预测 -> 电池配置。
- 替代料关系推断。
- 其他业务域的数据源切换。

---

## 三、数据源优先级

| 阶段 | 数据源 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 开发期 | Excel 入库 | 当前可用 | 允许作为开发期过渡数据源 |
| 正式期 | SAP 业务视图 | 最高 | SAP 权限和视图字段下发后作为正式优先源 |
| 兼容期 | Excel 旧数据 | 低于 SAP | 继续保留，但标记为 `manual_import_source` |

---

## 四、Excel 开发期规则

- 一期开发阶段允许 Excel 入库。
- Excel 入库用于支撑 BOM 一期查询、对比、导出和验收联调。
- Excel 数据必须标记来源，建议统一标记为 `manual_import_source` 或等价来源字段。
- Excel 模式是开发阶段过渡方案，不是 SAP 接入后的正式优先源。

---

## 五、SAP 正式优先规则

SAP 权限下来后：

- SAP 视图作为正式优先源。
- 同一 `订单号 + 版本号` 同时存在 SAP 和 Excel 数据时，以 SAP 为准。
- SAP 数据和 Excel 数据必须共用同一套唯一键。
- SAP 字段必须映射到当前字段字典定义的逻辑字段。

---

## 六、冲突优先级

| 冲突场景 | 处理规则 |
| --- | --- |
| SAP 与 Excel 存在同一订单号 + 版本号 | 以 SAP 为准 |
| SAP 有数据，Excel 无数据 | 使用 SAP |
| SAP 无数据，Excel 有历史开发数据 | 可保留 Excel 数据并标记 `manual_import_source` |
| SAP 与 Excel 材料行同键冲突 | 以 SAP 材料行为准 |
| SAP 字段缺失或映射失败 | 标记异常，进入人工确认，不用 Excel 静默覆盖 SAP |

---

## 七、唯一键共用规则

Excel 导入和 SAP 导入共用以下唯一键：

- BOM 头唯一键：`订单号 + 版本号`
- 材料行唯一键：`订单号 + 版本号 + SAP编码`

如果后续 SAP 视图存在更强唯一键，可在不破坏上述逻辑键的前提下增加技术主键。

---

## 八、SAP 切换前置条件

正式切换到 SAP 前，至少需要满足：

- SAP 权限已下发。
- SAP 业务视图名称明确。
- SAP 字段字典已映射到 BOM 逻辑字段。
- SAP 数据样例已完成验收。
- Excel 与 SAP 同键冲突样例已验证。
- 数据 owner 已确认切换窗口。

---

## 九、SAP 切换动作

SAP 切换时必须执行：

1. 重跑入库。
2. 重建索引。
3. 重做去重。
4. 重算来源优先级。
5. 重跑一期问题集回归。
6. 核对导出结果与查询结果一致性。

---

## 十、SAP 接入后 Excel 模式下线原则

- SAP 正式接入后，Excel 不再作为默认查询源。
- Excel 旧数据可以保留，但必须带 `manual_import_source` 标记。
- 新增业务数据原则上不再通过 Excel 手工导入承载正式口径。
- 若因 SAP 临时不可用需要使用 Excel 回补，必须经数据确认人确认。

---

## 十一、回滚 / 兼容说明

当前尚未进入 SAP 接入实现，以下内容后续补齐：

- SAP 切换失败后的自动回滚机制。
- SAP 与 Excel 双源灰度查询策略。
- SAP 接入失败时是否允许临时回退 Excel。
- 回滚后的索引恢复和导出文件一致性校验。

在上述工程方案未补齐前，不允许把 SAP 切换视为已经完成。

---

## 十二、当前结论

当前 BOM 一期可以按 Excel-first 开发期模式正式 Go。

正式 Go 不代表 SAP 已接入；SAP 是后续正式源切换目标。
