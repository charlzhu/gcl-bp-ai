# 产销存 M4-6 业务验收与真实问法回归样例固化

## 1. 本轮目标

本轮目标是把产销存经营分析 M4 已接入的智能问答能力，固化成可重复执行的真实问法回归样例，防止后续改动导致业务口径退化。

本轮不扩展到 SAP 物管、物流 NL2SQL、计划 BOM 或完整多 Agent 编排。

## 2. 当前仓库能力判断

### 已完成能力

1. 产销存 Excel 解析与中间库事实模型已存在。
2. 产销存查询执行器已支持流量、时点、预算达成率等确定性计算。
3. 产销存智能问答服务已接入后端和前端业务域入口。
4. M4-4 focused、M2/M3 回归、编译、静态扫描和前端 build 已有验收记录。

### M4-6 补齐能力

1. 新增 19 条真实业务问法回归样例。
2. 覆盖销量、销售量、发货量、库存、存货、寄存、开票销量、预算达成率、按基地、按版型、季度、累计、未发布年份、同比/环比、库存周转率等边界。
3. 修复中文季度、截至/截止累计、按版型产量、同比/环比误答等问法缺口。
4. 所有新增验收样例均走智能问答主链路，不绕过中间库和后端确定性计算。

## 4. 业务口径固化

1. “销量 / 销售量 / 发货量”在当前产销存范围内按同一业务指标处理。
2. 2024 年销量默认使用“组件事业部剔除内部交易”的对外销量口径。
3. “库存 / 存货 / 存货合计 / 库存（SAP 数据）”按同一库存时点指标处理。
4. “寄存仓 / 寄存合计”按同一寄存库存时点指标处理。
5. “截至 N 月 / 截止 N 月 / 前 N 个月 / 累计到 N 月”按年初至 N 月已发布月份累计处理。
6. “N 月至 M 月 / N 月到 M 月”等任意月份区间当前暂不开放，必须业务化阻断，不能误答成年初累计。
7. “Q1 / 一季度 / 第 1 季度”等季度问法应等价。
8. 同比、环比、库存周转率等当前缺少完整业务口径的问题必须先业务化澄清或暂不支持，不能误答或编造。

## 6. 边界说明

1. 本轮只固化产销存真实问法回归，不处理 SAP 物管任务。
2. 本轮不让模型直接计算业务事实，所有业务结果由后端确定性链路产生。
3. 本轮不修改物流、计划 BOM、功率预测主链路。
4. 本轮不新增管理 token，不修改 `.env`，不提交真实连接信息。
