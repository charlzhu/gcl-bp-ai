## 四、一期验收问题范围

一期验收以 `BOM问题_答案.xlsx` 中已有标准答案的问题为主要依据。

一期必须覆盖的能力：

- 单订单 5 类核心材料规格查询。
- 多订单材料规格表格展示。
- 两订单材料差异对比。
- 评审号别名定位。
- 歧义订单候选列表或澄清提示。
- 当前查询结果导出。

标准答案说明：

- 标准答案以业务确认版本为准。
- 当前 `BOM问题_答案.xlsx` 中已有答案的题目可作为验收候选。
- 题目中的口语材料名按正式映射规则处理。

## 七、特殊题目边界说明

### 1. 占位订单号题目

处理规则：

- 保留题目原文。
- 标记为“后续补答题”。
- 不纳入一期验收。
- 业务替换真实订单号后重新生成标准答案。

### 2. 同一订单和自己对比

处理规则：

- 保留题目原文。
- 一期应返回“无差异”或“题面重复，请确认是否需要对比其他订单”。
- 不应当报系统异常。

### 3. 歧义订单号题目

处理规则：

- 如果短订单号或评审号命中多个订单，返回候选列表。
- 候选列表由业务选择后再继续查询。
- 未选择前不强行返回某一个订单结果。

### 4. 功率预测题目

处理规则：

- 明确划入二期。
- 一期不做电池配置推荐。
- 如果用户提出该问题，应提示该能力不在当前一期范围内。

## 八、验收通过标准

一期验收建议按以下标准判断：

- 能按订单号 / 订单名称 / 评审号别名定位 BOM。
- 能返回 5 类核心材料的原始物料名称和描述。
- 能处理同类材料多行命中并全部返回。
- 能对两个订单按底层物料行做差异对比。
- 能对歧义订单返回候选列表或澄清提示。
- 能对当前查询结果执行异步导出。
- 不把 5 条剔除题计入一期验收失败。

## 九、仍需工程实现阶段细化的事项

- 标准答案比对是完全匹配还是关键字段匹配。
- 导出文件生成、分段和下载状态的接口协议。
