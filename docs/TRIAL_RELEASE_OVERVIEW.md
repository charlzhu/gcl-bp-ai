# 经营计划智能助手试运行发布说明

## 系统名称

经营计划智能助手。

## 试运行范围

本次发布包面向两个已经完成试运行准备的能力：

- 物流数据问答
- 计划 BOM 问答

当前不是继续后端 Wave 开发，不迁 A，不扩 query_key，不做 demo 页面。

## 已具备能力

### 物流数据问答

- 当前能力分布：`A=656 / B=178 / C=69 / D=0`
- 已打通真实业务链路。
- 已接入 qwen-plus 答案表达层。
- 前端动态展示已通过。
- 可进入小范围业务试运行。

### 计划 BOM 问答

- 当前能力分布：`A=86 / B=40 / C=3 / D=0`
- 正式问题来源：`BOM问题.xlsx`，有效问题 `129` 条。
- 数据来源：`BOM 源数据.zip`，`34` 个 Excel，`4034` 条材料行。
- 上传接口：`POST /api/v1/plan-bom/upload`
- 问答接口：`POST /api/v1/plan-bom/qa/ask`
- QA API E2E：`30/30`
- NLU live：`129` 次调用，采纳 `126`
- 答案表达层 live：`30/30`
- 可进入小范围业务试运行。

## 当前可以承诺的能力

- 对已收口的 A 类问题，基于真实结构化数据给出答案。
- 对信息不完整的 B 类问题，给出业务可理解的追问。
- 对当前数据或规则无法支撑的 C 类问题，说明不能回答的原因。
- 物流和 BOM 均支持前端页面试运行。
- BOM 支持 Excel 上传后进入问答链路。
- 答案表达层只优化展示，不改变确定性事实。

## 当前不能承诺的能力

- 不承诺所有问题都直接回答。
- 不承诺开放式预测、经营判断、策略建议类问题直接给结论。
- 不承诺 BOM 功率倒推、电池方案反推等缺业务规则的问题。
- 不承诺非核心 BOM 材料都进入核心五类明细/对比查询。
- 不承诺 LLM 直接生成 SQL 或替代正式 planner。

## LLM 边界

- LLM 不查数。
- LLM 不生成 SQL。
- LLM 不改写业务边界。
- LLM 不把 B/C 包装成 A。
- LLM 只做理解辅助和表达优化。
- 所有订单、物料、版本、规格和统计结果必须来自确定性数据链路。

## 试运行适用对象

- 物流业务同事：验证物流数据问答是否能覆盖日常统计、对比、追问和拒答场景。
- 计划 BOM 业务同事：验证 BOM 上传、关键材料查询、跨订单对比、追问和拒答解释。
- 部门负责人：查看系统是否具备小范围推广和按周反馈闭环条件。

## 风险控制

- A/B/C/D 分层不硬迁。
- B/C 问题保持追问或拒答边界。
- qwen-plus 仅作为候选理解和表达层，不作为事实源。
- Guardrail bounded 检查已验证 B/C 不被 LLM 放行为 success。
- 试运行反馈按 A 答错、B 追问不好、C 拒答不合理、数据问题、业务口径问题、前端体验问题、系统 Bug 分类闭环。
