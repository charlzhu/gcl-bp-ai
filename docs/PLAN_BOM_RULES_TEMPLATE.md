## 四、一期范围

### 1. 一期纳入范围

- 按订单号、订单名称、评审号别名定位 BOM。
- 查询 5 类核心材料规格：玻璃、间隙膜、互联条、汇流条、接线盒。
- 支持两订单材料差异对比。
- 支持多订单表格展示。
- 支持版本号展示和当前版本判定。
- 支持当前查询结果导出，格式为 `xlsx` 和 `csv`。

### 2. 一期不纳入范围

- 不做“功率预测 -> 电池配置”推荐，该能力明确划入二期。
- 不做替代料关系结构化推断。
- 不做不限定范围的全量无限制单文件导出。
- 不做 SAP 正式视图接入开发，SAP 只作为后续正式源切换目标。

## 五、评审号查询规则

### 1. 基本规则

- 前端输入“评审号”时，后端直接查 `订单号`。
- 允许“评审号”作为“订单号”的别名进入词典。
- 示例中的 `创维-01182` 这类输入，直接拿完整字符串查，采用类似 `LIKE` 的匹配模式。
- 如果一个问题里同时给了订单号和评审号，以订单号优先。

### 2. 多命中规则

- 如果评审号别名匹配命中多个订单，返回候选列表给业务选择。
- 候选列表至少应展示订单号、订单名称、版本号、来源类型。
- 候选列表数量上限、排序规则和交互协议属于后续工程实现细节，不阻塞一期规则 Go。

## 六、当前版本判定规则

当前版本按以下顺序判定：

1. 先按 `生效日期` 倒序。
2. 若 `生效日期` 相同或缺失，再按 `版本号` 倒序。
3. `版本号` 比较按自然序，不按字符串字典序，例如 `A2 < A10`。
4. 若生效日期和版本号均无法判定，返回“版本待人工确认”。

说明：

- 当前版本规则已经从“待确认”升级为“可执行规则”。
- 后续实现时不得直接按字符串字典序比较版本号。

## 七、核心口语映射规则

| 业务口语 | 标准材料类别 | 查询命中方式 | 返回展示 |
| --- | --- | --- | --- |
| 间隙贴膜 | 间隙膜 | 物料名称 + 描述 | 原始物料名称 |
| 焊带 | 互联条 | 物料名称 + 描述 | 原始物料名称 |
| 线盒 | 接线盒 | 物料名称 + 描述 | 原始物料名称 |
| 玻璃 | 光伏玻璃 | 物料名称 + 描述 | 原始物料名称 |

补充规则：

- 同一个订单中如果出现多个 `间隙膜 1/2`、多个 `互联条`，需要全部取出。
- 查询时同时看 `物料名称` 和 `描述`。
- 返回时显示 BOM 原始物料名称，不把原始名称强行改成口语名称。
- 差异对比时按底层物料行比较，不按映射后的 5 类粗暴合并。

## 八、主键与版本链规则

| 对象 | 唯一键 |
| --- | --- |
| BOM 头 | 订单号 + 版本号 |
| 材料行 | 订单号 + 版本号 + SAP编码 |

版本链规则：

- 版本链一定可按大小排序。
- 版本号按自然序比较。
- 如果后续发现同一 `订单号 + 版本号 + SAP编码` 下仍存在重复材料行，再评估是否追加 `序号` 或其他辅助字段。

---

## 九、替代料一期边界

替代料规则如下：

- 替代料是一对多关系。
- 不区分主替代 / 次替代。
- 没有生效条件。
- 一期不做替代料关系推断。
- 仅当 `备注 / 修订内容 / 物料名称` 中出现明确替代标识时，原样展示。
- 不做结构化拆解，不输出推断出的替代料关系图。

## 十、数据源与切换规则

数据源规则详见 `PLAN_BOM_SOURCE_SWITCH_RULE.md`。

本规则文件只保留结论：

- 一期开发阶段允许 Excel 入库。
- SAP 权限下来后，SAP 视图为正式优先源。
- 同一 `订单号 + 版本号` 同时存在 SAP 与 Excel 数据时，以 SAP 为准。
- Excel 旧数据继续保留，但标记为 `manual_import_source`。
- Excel 导入和 SAP 导入共用同一套唯一键。

---

## 十一、导出规则

导出规则详见 `PLAN_BOM_EXPORT_SPEC.md`。

本规则文件只保留结论：

- 一期必须支持导出。
- 支持 `xlsx` 和 `csv`。
- 只导出当前查询结果。
- 单文件最大 500 行。
- 结果过大时自动分段导出。
- 导出方式为异步导出。
- 文件保存时间为一周。
- 不支持单文件无限制全量导出。

---

## 十二、空结果与异常边界

| 场景 | 处理方式 |
| --- | --- |
| 订单号不存在 | 返回条件无匹配 |
| 订单名称不存在 | 返回条件无匹配 |
| 评审号别名无匹配 | 返回条件无匹配，提示可补充订单号或订单名称 |
| 评审号别名命中多个订单 | 返回候选列表，等待业务选择 |
| 指定订单下缺某类材料 | 返回正常空结果，并说明缺失的材料类别 |
| 当前版本无法判定 | 返回“版本待人工确认” |
| 导出失败 | 返回“系统异常，导出失败，请联系管理员” |

- 标准答案以业务确认版本为准。
- `BOM问题_答案.xlsx` 中已有答案的题目可作为一期验收题候选。

## 十四、Go / No-Go 结论

基于本次文档收口，建议：

> **BOM 一期完整范围可以从 Conditional Go 推进到正式 Go。**

正式 Go 的含义：

- 可以进入 BOM 一期代码设计和最小实现阶段。
- Go 范围仅限本文件定义的一期能力。
- 不代表 SAP 正式接入已完成。
- 不代表二期功率预测、电池配置、替代料关系推断已纳入。
