# 物流域 B 类高频题澄清模板细化

## 1. 目标

本轮目标不是扩新 `query_key`，而是在当前 B 类题已经会澄清的基础上，把高频题从“通用澄清”继续收口成“业务化澄清模板”。

当前策略要求：

- B 类题必须返回 `needs_clarification = true`
- 不允许误落成 `success`
- 不允许对时间、指标、异常定义不清的问题直接乱算

## 3. 第一批已细化的高频模式

### 3.1 缺少统计时间的费用类问题

### 3.2 按运输方式统计“发运记录数”

### 3.3 规格总瓦数问题

当前追问要点：

### 3.4 高运费收货地址 / 项目地问题

- `RAW038` 统计一下24年创维客户发货的项目地运费金额超过20万的收货地址，并分别列出询比价和招标的发运量

当前追问要点：

### 3.6 状态拆分统计题

## 4. 当前仍走通用澄清的典型问题

当前仍有 `297` 条题没有专属业务模板，仍走通用兜底澄清。典型包括：

- 季度问法：
  - `Q026` 2024Q1的物流发运车次或车辆数是多少？
- 装载效率类：
  - `Q037` 2024-01从合肥始发的订单中，平均每车装载托数是多少？
- 复杂数据质量 / 填充率类：
  - 某些字段填充率、异常值识别、分组对比题

这些题并不是“已支持”，只是当前尚未细化到专属澄清模板，因此仍然走正式通用澄清。

## 5. 分批细化方案

### 第一批：本轮已完成

目标：

- 先覆盖高频且口径边界清楚的 B 类模式
- 优先解决“通用澄清太泛”的问题

已完成范围：

- 缺少统计时间的费用类
- 运输方式记录数
- 规格总瓦数
- 高运费地址明细
- 模糊异常 / 好坏评价题
- 状态拆分统计题
- 一部分拆分型“分别是多少”

### 第二批：建议继续收口

建议优先细化：

- 季度 / Q1 / Q2 / Q3 / Q4 问法
- 平均每车装载托数 / 装载效率类
- 更复杂的字段填充率 / 数据质量类
- 更复杂的多维拆分题

### 第三批：按价值补充

建议最后处理：

- 低频边界题
- 需要更多业务定义才能稳定追问的题
- 可能最终会转成 C 类不支持的题
