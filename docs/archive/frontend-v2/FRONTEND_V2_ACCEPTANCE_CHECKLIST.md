# FRONTEND_V2_ACCEPTANCE_CHECKLIST.md

## 一、文档用途

本文件用于作为《前端查询页第二版优化（收敛版）》的验收清单。

适用对象：

- 项目接手者
- 联调人员
- 验收人员
- 后续做 V2.1 稳定性补强的开发者

---

## 二、验收结论

当前前端 V2 已按既定目标验收通过。

---

## 三、验收清单

### 1. 自然语言查询页

- 能输入自然语言问题并正常发起查询
- 能展示 `parsed` 结构化结果
- 能展示状态码
- 能展示执行模式
- 能展示模板命中信息
- 能展示结果摘要
- 能展示汇总指标
- 能在有结果时展示结果表格
- 能在空结果时展示空结果分析

### 2. 条件查询页

- 能按指标、来源范围、月份发起查询
- 能按客户、物流公司、区域、始发地、运输方式筛选
- 能展示结果摘要
- 能展示状态和执行模式
- 能展示汇总指标
- 能在空结果时展示提示信息
- 能从结果进入明细页

### 3. 结果表格

- 表头顺序稳定
- 常见字段显示中文表头
- 数值具备基础格式化
- 空值统一显示 `-`
- 长文本可 tooltip 查看
- 表格支持横向滚动
- 单击整行可查看详情
- “查看”按钮可查看详情
- 按钮点击不会引发异常重复跳转

### 4. 明细视图

- 能展示当前查询概览
- 能展示当前激活记录
- 能展示来源类型
- 能展示 `source_ref`
- 能展示解析与执行上下文
- 能查看完整原始响应
- 从明细页返回时查询条件不丢

### 5. 查询历史页

- 能加载历史问题列表
- 能展示执行模式
- 能展示模板命中
- 能展示状态码
- 能查看历史详情
- 能重新查询
- 重新查询后能进入对应查询页

### 6. 查询上下文保留

- 自然语言查询页可恢复最近一次问题
- 条件查询页可恢复最近一次筛选条件
- 最近一次查询结果可恢复
- 最近一次 `parsed` 可恢复
- 查询页 -> 明细页 -> 返回查询页链路可用

### 7. 结果解释展示

- 正常结果与空结果在视觉上明显区分
- 自然语言查询页不再以原始 JSON 为主展示解释
- 条件查询页已具备最小兼容解释能力
- 执行模式、状态码、模板命中可视化展示正常

## 四、建议验收场景

### 1. 正常统计场景

- `2025年3月运量是多少`

验收点：

- 结果摘要正常
- 汇总指标正常
- 表格列顺序正常

### 2. 对比场景

- `2025年3月和2026年3月运量对比`

验收点：

- 差值显示正常
- 差异率百分比格式正常
- 状态与解释不冲突

### 3. 明细场景

- `合同编号GCL5010ZJ202503015的明细`

验收点：

- 行点击可查看详情
- “查看”按钮可查看详情
- 明细页可展示完整上下文

### 4. 空结果场景

- `合同编号ERR001的明细`

验收点：

- 状态码明确
- 空结果分析正常
- 页面未被表格增强逻辑破坏

### 5. 条件查询空结果场景

- 月份设置为一个无数据月份后发起统计

验收点：

- 条件查询页可展示空结果提示
- 兼容解释与兼容提示同时正常显示
