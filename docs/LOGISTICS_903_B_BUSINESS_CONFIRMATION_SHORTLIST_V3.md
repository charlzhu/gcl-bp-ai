# B=178 业务确认交付包 v3（业务简洁版）

这份清单用于业务同事确认口径，不要求业务理解 query_key 或代码实现。

## 异常/风险/评价标准（26 条）

- 现在不能直接答：异常、风险、最差、达标等判断标准未锁定，直接回答会引入主观判断。
- 请确认：请确认阈值、比较基准、评价指标和输出粒度。
- 确认后系统处理：确认口径后新增受控 query_key 或参数化规则；未确认前继续 B。

## 数据字段/数据覆盖（16 条）

- 现在不能直接答：当前系统缺少可验证字段、历史覆盖或数据源支撑，不能直接给统计结果。
- 请确认：请确认字段是否存在、数据是否覆盖、历史/系统来源如何取数。
- 确认后系统处理：补字段或补数据源后迁 A；若确认无数据支撑，则转 C 或继续 B 追问。

## 综合业务口径（8 条）

- 现在不能直接答：问题缺少必要业务口径或数据边界，当前不应直接回答。
- 请确认：请确认指标、时间、维度、数据源和业务定义。
- 确认后系统处理：确认后按 query_key 或追问模板纳入治理。

## 趋势/原因口径（4 条）

- 现在不能直接答：趋势和原因类问题需要比较基准或归因规则，当前不能由系统自由推断。
- 请确认：请确认同比/环比/均值比较方式，以及原因归因字段和优先级。
- 确认后系统处理：确认后进入 A 或部分转 C；未确认前保持澄清。
