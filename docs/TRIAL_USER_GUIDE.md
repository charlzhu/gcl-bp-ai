# 业务试运行操作手册

## 如何进入系统

打开试运行环境前端地址，进入左侧菜单中的：

- 物流数据问答
- 计划 BOM 明细查询

如果页面无法打开，请先反馈给系统管理员，不需要重复刷新或重新上传文件。

## 如何提物流问题

在物流数据问答页面输入自然语言问题，例如：

- 2026年1月份总发运量是多少MW？总共发了多少车次？
- 江苏省历史发运的总费用是多少？
- 2026年各承运商的签收率分别是多少？

系统会根据已有物流数据返回结果、表格或说明。

## 如何提 BOM 问题

在计划 BOM 页面输入 BOM 相关问题，例如：

- 订单00104的玻璃、间隙贴膜、焊带、汇流条、接线盒的规格描述？
- 哥伦比亚COEXITO-2026-00067，NT10/78GDF的线盒物料描述。
- 哪些订单的接线盒规格不一样，按订单列出来。

系统会优先从真实 BOM 数据中查询，不会凭空生成规格。

## 如何上传 BOM Excel

1. 进入计划 BOM 页面。
2. 找到 BOM Excel 上传入口。
3. 选择 `.xls`、`.xlsx` 或 `.xlsm` 文件。
4. 点击上传。
5. 上传成功后查看解析订单数、材料行数、 warning 和 error。
6. 上传后即可在 BOM 问答入口提问。

## 什么问题可以直接问

- 明确订单号的关键材料规格。
- 明确订单范围的多订单材料清单。
- 明确对比对象的订单间材料差异。
- 明确材料名称的物料描述查询。
- 物流中明确时间、范围、指标的统计问题。

## 什么问题系统会追问

如果问题缺少关键条件，系统会追问。例如：

- 没有说明订单范围。
- 没有说明材料范围。
- 没有说明对比对象。
- 没有说明版本。
- 使用了“这批订单”“核心材料”“是否复用”等需要业务口径的问题。

用户可以按系统追问补充订单号、年份、客户、国家、型号、材料范围或业务定义。

## 什么问题系统会解释不能回答

以下问题当前可能无法直接回答：

- 预测未来费用或未来发运结果。
- 用功率倒推 BOM 配置。
- 要求系统判断业务策略是否合理。
- 当前数据中没有对应订单或材料。
- 需要外部规则、工艺规则或人工判断的问题。

这类问题不是系统故障，系统会说明缺少什么数据或规则。

## 如何反馈系统问题

请记录：

- 原始问题；
- 系统返回状态；
- 你认为正确的答案或期望；
- 订单号或材料类别；
- 是否是数据问题、口径问题、页面问题或系统 Bug。

反馈时尽量保留截图和原始问题文本，便于复盘。

## 示例问法

- 2026年1月份总发运量是多少MW？总共发了多少车次？
- 最近物流成本是不是变高了？
- 预测下个月物流费用会是多少？
- 订单00104的玻璃、间隙贴膜、焊带、汇流条、接线盒的规格描述？
- 订单00067和订单00106的五类关键材料有什么不一样？
- 多个订单的关键材料规格做成表格。
- 使用功率预测来问询 BOM 配置需要什么电池？
